# 📖 What is a Framework?

## Definition

A framework is a reusable software structure that provides predefined tools, libraries, and best practices to build applications efficiently.

---

ഒരു വീട് പണിയാൻ Blueprint ആവശ്യമായതുപോലെ, software develop ചെയ്യാൻ Framework സഹായിക്കുന്നു.

# 💻 Java Example

```java
public class Employee {

    public void display() {
        System.out.println("Welcome to Employee Management System");
    }

    public static void main(String[] args) {
        Employee employee = new Employee();
        employee.display();
    }
}
```

---

# 📝 Program Explanation

- `Employee` → Class
- `new Employee()` → Creates an Object
- `display()` → Calls the method
