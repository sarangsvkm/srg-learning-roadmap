# 📖 What is Spring?

## Definition

Spring is an open-source Java framework used to build enterprise applications.

---

## 🇮🇳 Malayalam Explanation

Spring ഒരു Java Framework ആണ്.

ഇത് Enterprise Applications develop ചെയ്യാൻ ഉപയോഗിക്കുന്നു.

Spring വന്നതോടെ Java development വളരെ എളുപ്പമായി.

Developer-ന് configuration കുറയ്ക്കാനും clean code എഴുതാനും സഹായിക്കുന്നു.

# ❓ Why was Spring Created?

Before Spring:

- Complex Configuration
- Tight Coupling
- Difficult Testing
- More Boilerplate Code

Spring solves these problems.

---

# ⭐ Features of Spring

- Dependency Injection (DI)
- Inversion of Control (IoC)
- Spring MVC
- Spring Data JPA
- Spring Security
- Transaction Management

---

# 🏢 Where is Spring Used?

- Banking Systems
- ERP Applications
- CRM Systems
- E-commerce
- Hospital Management
- Cloud Applications

---

# 💻 Java Example

```java
public class Welcome {

    public void message() {
        System.out.println("Welcome to Spring Framework");
    }

    public static void main(String[] args) {
        Welcome welcome = new Welcome();
        welcome.message();
    }
}
```

---

# 📝 Program Explanation

- `Welcome` → Class
- `new Welcome()` → Creates Object
- `message()` → Calls the method

# 🎤 Interview Questions

## Q1. What is Spring?

**Answer**

Spring is an open-source Java framework used to develop enterprise applications.

---

## Q2. Why do we use Spring?

**Answer**

Spring simplifies Java development and provides features like Dependency Injection, Spring MVC, and Spring Security.
